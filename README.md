# Josia Joseph Ntahudi — Portfolio

Responsive static portfolio, updated with HAP, TSG, ERP, TFT, spreadsheet automation, and marketing projects.

## Open locally

Open `index.html` in a browser, or run `python -m http.server 8000` in this folder and visit `http://localhost:8000`.

## Structure

- `index.html` — homepage with interactive project-category filters
- `projects/` — six case studies, including original spreadsheet project
- `style.css` — existing visual base
- `design.css` — modern responsive refinements (desktop/tablet/mobile)
- `script.js` — navigation, language, theme, animations, filters, WhatsApp form
- `assets/images/cases/` — 30 actual project screenshots plus optimized card thumbnails
- `case-gallery.css` and `case-gallery.js` — responsive screenshot galleries and fullscreen viewer

## Notes

HAP, TSG, and ERP case studies use actual screenshots supplied by the project owner. PHP/CodeIgniter/MySQL and related stack information is owner-reported, not independently code-verified. Bootstrap CSS is bundled locally in `vendor/` (v5.3.6), and mobile navigation/project filters run without Bootstrap JavaScript. Vector icons are bundled locally in `vendor/icons/` with attribution in `vendor/ICONS-ATTRIBUTION.txt`. The Inter font loads from Google Fonts when available and otherwise uses a system sans-serif fallback.

## Real screenshots (HAP, TSG, ERP)
- Replaced previous illustrative concepts in the three portfolio cards and case studies with screenshots supplied as HAP.zip (12), TSG.zip (6), and SISTEM ERP.zip (12). Screenshots are displayed in curated, responsive galleries with click-to-zoom, arrow/ESC navigation, and mobile swipe.
- Screenshots are cropped to remove the browser interface and ERP personal identifiers are blurred in login and user-list images.
- CodeIgniter, PHP, MySQL, HTML, CSS, JavaScript, Bootstrap, VS Code, and XAMPP are stated by the project author; screenshots alone do not verify source code or backend operation.
- The portfolio is a static presentation; it does not bundle, deploy or publicly expose the actual ERP code or database.

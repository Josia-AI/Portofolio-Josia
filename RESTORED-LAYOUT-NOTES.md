# Layout restored + TFT content update

This release uses the **pre-monochrome S.Kom. portfolio layout** supplied by the user (blue-accent design.css, original desktop/mobile hierarchy) rather than the previous experimental monochrome layout.

**Light Mode / Dark Mode** is a selectable preference, accessible from the theme-toggle icon and persisted in localStorage across all pages. Light Mode retains a bright design with accent colors; Dark Mode uses black/charcoal with readable typography.

## TFT updates
- 13 actual TFT images: six customer site screens and seven admin portal screens.
- Responsive two-part gallery, accessible full-screen slideshow with swipe, arrows, and Escape.
- Overview + feature explanations for interactive fabric catalog, search/filter, sample enquiries, and admin/product management.
- Technology: PHP, CodeIgniter, MySQL, HTML5, CSS3, JavaScript, Bootstrap, VS Code, XAMPP (developer-reported).
- Keeps previous TFT demo video and website project navigation.

## Notes
- HAP, TSG, ERP, spreadsheet and marketing pages are restored from the last pre-monochrome portfolio package and remain intact.
- Portfolio is static and can be hosted on a conventional web server without running its showcased backend systems.
- All updated TFT images are part of this ZIP.

TFT CREATION TEXTILE / PROJECT 04

TFT Creation
Website & Admin System.

Development of a textile website with an interactive product catalog, fabric discovery tools, sample inquiries, and a dedicated administrative dashboard. Pengembangan website tekstil dengan katalog produk interaktif, filter kain, permintaan sampel, serta dashboard khusus untuk pengelolaan data dan produk.

PROJECT OVERVIEW GAMBARAN PROJEK

I built a responsive B2B textile website and admin interface to connect customers with fabric products and help administrators manage the catalog. Saya membangun website bisnis tekstil B2B yang responsif, lengkap dengan katalog kain, fitur pelanggan, dan sistem administrasi produk.

The project combines PHP and CodeIgniter on the backend, MySQL for data storage, and HTML, CSS, JavaScript and Bootstrap for responsive, interactive user interfaces. Development used VS Code and XAMPP. Website dikembangkan menggunakan PHP dan CodeIgniter di backend, MySQL sebagai database, serta HTML, CSS, JavaScript, dan Bootstrap untuk antarmuka responsif. Pengembangan dilakukan melalui VS Code dan XAMPP.
